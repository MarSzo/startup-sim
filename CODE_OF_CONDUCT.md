# Zasady współpracy

Chcemy, żeby praca nad grą była przyjemna dla wszystkich.

- Bądź życzliwy i cierpliwy; zakładaj dobre intencje.
- Krytykuj kod i pomysły, nie ludzi.
- Żadnych obelg, nękania, dyskryminacji ani treści o charakterze seksualnym
  w Issues, pull requestach i komentarzach.
- Nie publikuj cudzych danych osobowych.

Opiekunowie mogą edytować lub usuwać wpisy łamiące te zasady i blokować osoby,
które je powtarzają. Problem możesz zgłosić prywatnie opiekunowi projektu
([@mateuszpalak](https://github.com/mateuszpalak)).

Zasady wzorowane na [Contributor Covenant](https://www.contributor-covenant.org/).
